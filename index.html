Selected Projects

Rewind: Exactly-Once Execution for LLM Agents

2026

Crash-safe side effects for AI agents: an effect ledger for LangGraph that makes every real-world tool call (a refund, an email) happen exactly once, be safely skipped if the world changed, or be escalated to a human, even when the agent crashes and resumes.

  • Built a drop-in LangGraph tool node backed by a PostgreSQL effect ledger: an intent, dispatch, confirm state machine with step-derived idempotency keys, lookup-based recovery for ambiguous errors and timeouts, precondition re-validation after downtime, lease and fencing tokens against zombie workers, and saga compensation.
  • Benchmarked 2,600 crash-injection trials across 13 failure scenarios against LangGraph, Temporal, DBOS, and agent-ledger, counting outcomes from Stripe and the mail inbox rather than each system’s own ledger: 0 duplicate refunds per 1,000 crashes versus 167–667 for the baselines, at 3.4 ms median overhead per tool call.
  • Cross-validated on real Stripe test mode (240 trials, 79 of 80 cells matched the simulated Stripe) and documented the one remaining failure mode, a frozen worker waking before an email send. About 2,000 lines of source with 93 tests, including property-based tests, run in CI.
  • Python
